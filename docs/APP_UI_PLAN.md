## 1. 원칙
- 보기: 사진으로 찍은 종이 미니어처(동화 화면과 같은 판). 화면 장식도 **종이**(크림 카드, 갈색 잉크, 얇은 크라프트 테두리, 그림자). 펠트·바느질 없음.
- 아이패드 먼저, 가로·세로 둘 다. 누르는 곳은 **80pt 이상**(화면 묶음을 pt 단위로 그려 기기마다 같은 크기, `AppUI.px_per_pt`).
- 광고 없음, 분석 도구 없음, 로그인 없음. 기록은 기기 안(`user://app/state.json`).
- 보호자 글은 합쇼체("눌러 주세요", "열렸습니다"), 아이 글은 해요체("잠겨 있어요") — 톡톡 51939c3b.
- 동화는 이야기만 전한다(퀴즈·교훈 없음). 화면 묶음도 아이에게 돈 이야기를 하지 않는다: 잠긴 책은 "어른에게 보여 주세요"만.

## 4. 창작 동화 이름 녹음 (톡톡 373ad128 방식)
- 이름이 든 줄은 **이름 조각 + 고정 조각**으로 녹음해 두고 기기에서 한 클립으로 이어 붙인다. 사탕 마녀 14줄(쓰는 줄 10): 예 `[N:다현이랑]‖[S:친구들은 사탕 가게로 쪼르르 들어갔어요.]`, `[S:뿅!]‖[N:다현이가]‖[S:빨간 딸기가 됐어요!]`.
- 문안은 톡톡 확정본(name_split_spec.py): 이 앱에서 바뀐 줄 둘 — wc_114 "깜깜한 길이 다현이 덕분에 환해졌어요." → "다현이 덕분에 깜깜한 길이 환해졌어요."(톡톡 어순 수정), wc_042(지금 안 씀) "다현이가 넣어 줘." → "다현아, 네가 넣어 줘."
- 조각: 고정 조각 = 톡톡 앱 묶음 `audio/el/witch_candy/parts/ko_<sig>.mp3`, 기본 이름 조각 = 톡톡이 빌드에 고른 녹음(그 줄의 앞뒤 문맥으로 녹음한 것). `tools/app/name_pieces.py` 가 복사·다듬어(톡톡 polish 의 EQ·압축, 16bit 24kHz WAV, importer keep) `game/audio/voice/witch_candy/name/` 에 두고, 줄 대응표 `pieces.json`(줄 id ↔ 톡톡 n·원본 경로·기본 완성본) 과 script.json 의 `segs[].pieces` 를 쓴다. 다시 씨앗(reseed)해도 `NAME_PIECES` 로 다시 붙는다.
- 잇기(`game/app/name_voice.gd`, 톡톡 engine/names.js assemble 과 같은 규칙): 앞뒤 무음 자르기(-45dB) → 이름 조각 음량을 고정 조각 평균에 맞춤(±6dB) → 6ms/12ms 페이드 → 조각 뒤 간격(쉼표 0.16 · 이름 뒤 0.05 · 감탄 '뿅!' 뒤 0.4 · 문장 끝 0.36 s) → 줄 음량(-16 LUFS, 미리 잰 값) → 부드러운 리미터 0.8 → AudioStreamWAV 하나. 한 줄 13ms 안팎.
- 아이 이름: 보호자가 이름(한글 1~4자)을 정하면 그 동화의 이름 조각만 서버가 녹음해 기기에 받는다 → `user://app/names/witch_candy/<줄>.wav`. 한 동화의 조각이 **모두** 오기 전에는 원래 이름(다현)으로 듣고 보이게 한다(TTS 없음). 자막은 `{A:이랑/랑}` 틀을 받침에 맞춰 채운다(지우 → 지우랑).
- 서버 경로(이 빌드에서는 부르지 않음, 다음 단계): 톡톡 서버 규칙 그대로 `POST /v1/name/run { tale }`(첫 설정) / `{ ticket: true }`(변경권 48시간) → `POST /v1/name/line { runId, tale, id, lang: "ko", piece: n, names: { A } }` → 이름 조각만 녹음. 이 앱에 맞출 점: (1) 응답을 **WAV(pcm_24000)** 로(Godot 는 mp3 를 기기에서 PCM 으로 못 푼다) — `fmt: "wav"` 인자, (2) 카탈로그에 이 앱의 줄 id(`wc_004` …)와 조각 번호, (3) `/v1/name/check` 로 금칙어 확인, (4) 영수증 검증 `/v1/receipt/apple` 에 이 앱 상품 ID. 서버는 이름을 저장·기록하지 않는다(톡톡과 같음).
- 시험(명령줄 녹화·회귀)은 언제나 기본 이름. 보호자 설정은 앱으로 연 동화에만 쓰인다.
